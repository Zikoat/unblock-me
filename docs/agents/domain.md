# Domain docs

This is a single-context repository.

Before exploring or changing the codebase, read `CONTEXT.md` at the repository root and relevant ADRs under `docs/adr/` when they exist. Missing domain files are normal and should not block work or trigger their creation. `/grill-with-docs` creates them when terminology or architectural decisions are actually resolved.

Use terms defined in `CONTEXT.md` consistently in issues, plans, tests, and code. If a needed concept is absent, reconsider whether new terminology is necessary and note genuine gaps for `/grill-with-docs`.

Surface any conflict with an existing ADR explicitly instead of silently overriding it.
