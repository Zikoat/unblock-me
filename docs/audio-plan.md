# Audio plan (your design)

The aim is a sound pack made by an audio designer (hired on Fiverr) or by an Opus or Fable agent. This page specifies the work well enough to hand over.

## What we build first

1. **A sound for every interaction:**
   - including those that are silent now;
   - one list of named sound slots, each with what triggers it.
2. **A debug block** that downloads the current sound pack and uploads a new one. The designer can then hear their sounds in the game without a build.
3. **A sound reel:** a video, recorded from the game, that runs through every sound slot in turn, with each slot labelled. The designer lays their sounds onto it while they work.

## What the designer delivers

- **A maximalist pack:** every slot has a sound, including the ones silent today.
- **A balanced pack:** the same sounds, with the unimportant ones muted or turned down.
- **The mix:**
  - the sounds are mixed well together;
  - tested on a phone speaker, a laptop, a headset and earbuds.
- **A theme song.** It is also used in the trailer.
- **Notes:** changes to animations they suggest, or would like to see.

## Format

To be settled when the debug block is built: one file per slot (OGG or MP3) plus a manifest naming each slot's file and volume. The pack is a zip.
